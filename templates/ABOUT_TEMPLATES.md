# About this folder

Adopter-ready files with placeholders (`owner-username`, `repo-name`, `package-name`, `owner-display-name`).

Copied to the repo root by:

```bash
npm run init
```

| File here | Destination |
|-----------|-------------|
| `package.json` | `package.json` |
| `README.md` | `README.md` |
| `LICENSE` | `LICENSE` |
| `CHANGELOG.md` | `CHANGELOG.md` |
| `CONTRIBUTING.md` | `CONTRIBUTING.md` |
| `SECURITY.md` | `SECURITY.md` |
| `CODE_OF_CONDUCT.md` | `CODE_OF_CONDUCT.md` |
| `dependabot.yml` | `.github/dependabot.yml` |
| `CODEOWNERS` | `.github/CODEOWNERS` |

The hosted **root** keeps [@open-templates](https://github.com/open-templates) branding for GitHub visitors.

See [`docs/INIT_TEMPLATE.md`](../docs/INIT_TEMPLATE.md).
